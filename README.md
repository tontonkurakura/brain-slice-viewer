# brain-slice-viewer

3D の脳モデルを任意の断面で切り、切り口に MRI と領域の色を出す。断面画像とモデルは
はじめから同じミリ座標に載せてあるので、両者を合わせる係数もキャリブレーションも要らない。

デモ: https://tontonkurakura.github.io/brain-slice-viewer/viewer.html

別のアプリで作り直す人は、最初の 3 節（動かす / 中が空っぽ / 座標）だけ通して読めばよい。
ファイル一覧・操作・データの素性は、必要になったときに引く参照部として置いてある。

## 動かす

clone して、静的ファイルを配るだけ。

```bash
python3 -m http.server 8791
# http://127.0.0.1:8791/viewer.html
```

ビルド手順は無い。依存は同梱の three.js (r163) だけで、外部への通信も発生しない。
回線の無い環境でも、ファイルを置けば開く。

## 3D モデルは、切っても中が空っぽ

脳の 3D モデルは、表面の三角形を集めたものでしかない。中身は無い。平面で切っても、
切り口に見えるのは殻の裏側だけ。実物なら現れるはずの白質も基底核も、モデルには存在しない。

そこで、切った位置の MRI 断面をその平面に貼る。脳を領域ごとに塗り分けた画像も重ねられ、
切り口が何という構造なのかまで読める。

成立の条件はひとつ。断面画像とモデルの位置が正確に一致していること。ずれていても画面は
もっともらしく見えるので、気づけるのは神経解剖を知っている人だけになる。

## 座標をひとつに畳むと、位置合わせのコードが消える

脳のおおよその中心を原点として、右を +X、前を +Y、上を +Z とするミリ単位の座標がある。
これを world RAS と呼ぶ。この実装は次の 4 つをすべてその数値で持つ。

| | 値 |
|---|---|
| GLB の頂点座標 | world RAS (mm) |
| 断面板を置く位置 | world RAS (mm) |
| クリップ平面の位置 | world RAS (mm) |
| 断面画像のスライス番号 | `slice_metadata.json` の `planes.<面>.world_coords` |

4 つが同じ数値だから、**座標を変換するコードがどこにも無い**。冠状断を y = −20.1 mm に
出す手順は、これで全部。

```
添字     = planes.coronal.world_coords.indexOf(-20.1)
タイル   = その添字
断面板   = y = -20.1
クリップ = y = -20.1
```

変換式を書きたくなったときは、たいていどこかで別の座標系が混ざっている。

この作りにしたのは、前の実装で痛い目を見たため。当時は 3D モデルが表示用にスケール・
センタリングされていて、断面と突き合わせるには変換が要った。その変換を「モデルの外形と
画像の外形を一致させる」という近似で作ったところ、3 軸で 3〜6% のスケール誤差が出たうえ、
前後軸にいたっては符号すら表現できず、前後がまるごと入れ替わる 165mm のずれになった。
前頭極を選ぶと後頭部が出る。それでも画面の上では、断面が動いているようにしか見えない。
座標系をひとつに畳めば、この種のずれはそもそも表現できなくなる。

## 別のアプリで作り直すなら

| 読むもの | 中身 |
|---|---|
| [docs/spec.md](docs/spec.md) | 座標の取り決め、断面の出し方、受け入れテスト、既知の落とし穴 |
| `assets/slice_metadata.json` | 実装が実際に読む値。スライス座標・タイルの並び・軸の向き |
| `viewer.html` | 上の 2 つを three.js で実装したもの。判断の理由はコメントにある |

three.js に固有なのはテクスチャアトラスの貼り方くらい。座標の扱いは描画エンジンに
依存しない。自前の 3D モデルを持ち込むなら、その頂点が world RAS に載っているかどうかを
機械で判定できる（spec.md の「既存の 3D モデルを使いたい場合」）。

## ファイル

| | |
|---|---|
| `viewer.html` | 本体。HTML / CSS / JS が 1 ファイル |
| `brain.glb` | DKT のモデル。93 領域 / 7.2MB / 頂点は world RAS (mm) |

| `assets/<面>/t1_atlas.webp` | MRI 断面 256 枚を 16×16 に敷き詰めた 4096×4096 / 不可逆 (q88) / アトラス間で共有 |
| `assets/<面>/label_atlas.webp` | 領域色の断面 (DKT)。可逆圧縮 |
| `assets/<面>/label_atlas_arterial.webp` | 領域色の断面 (血管支配)。可逆圧縮 |
| `assets/slice_metadata.json` | スライス座標 / タイルの並び / 軸の向き |
| `labels.json` | 領域名（日英）/ 大分類 / 色 / 代表スライス / 左右 |
| `vendor/three/` | three.js r163 無改変 (MIT) |
| `docs/spec.md` | 仕様 |

ラベル画像は可逆圧縮。画素の色から領域を逆引きするので、不可逆だと色が 1 ずれただけで
別の領域として解決されてしまう。

## 操作

モードの切り替えは右上の一番上。

| | 断面モード | 立体モード |
|---|---|---|
| 表示 | 断面板と、それで切ったモデル | モデルだけ（板もカットラインも出ない） |
| ホイール | 断面を 1 枚めくる（Shift で 10 枚） | 拡大縮小 |
| カーソルを乗せる | 断面上のその位置の領域名 | 最前面に見えている領域名 |
| 専用の操作 | 断面の向き / 位置 / 重ね方 / 切る向き | 半割 / 皮質の表示 |

| | |
|---|---|
| 左ドラッグ | 回転 |
| 中ボタンドラッグ | 拡大縮小（Ctrl + ホイールでも可） |
| アトラス（右上） | DKT ⇄ 血管支配 (ACA/MCA/PCA/VB) |
| 領域を選ぶ（左） | 強調する。断面モードでは代表スライスへ移動 |
| 左／右（左上） | 一覧に出す側。正中の構造は常に出る |

ホイールを断面めくりに使っている都合で、ズームは中ボタンと修飾キーに逃がしてある。
立体モードの「半割」は、クリップではない。反対側のメッシュを消している。皮質メッシュが
開いた殻なので、x=0 でクリップすると切り口から裏面が見えて中空になってしまうからだ。
脳幹と第三・第四脳室は左右を持たないため、半割しても残る。

## データの素性

使っているのは 1 例の標準脳。個人の MRI ではない。患者情報は含まれない。

| | |
|---|---|
| 標準脳 | MNI152。Connectome Workbench 由来 / 0.7375mm / 頭蓋剥離済みの HCP 系平均脳 |
| 領域分割 | FastSurfer が出す DKT。皮質は FreeSurfer の表面から、皮質下はラベルボリュームから起こしている。色は FreeSurferColorLUT |
| 血管支配 | [JHU Arterial Atlas](https://github.com/Chin-Fu-Liu/Arterial_Atlas) の Level 1 / 32 領域 |
| 表示の左右 | neurological（画像の左が患者の左） |

どの動脈が詰まるとどこが傷むかを脳全体に塗り分けた地図を、血管支配アトラスと呼ぶ。
同梱しているのは急性期脳梗塞 1,298 例の病変分布から作られたもの。MNI152 1mm のグリッドから
最近傍でこの標準脳の空間へ移してあり、側脳室の重心で 1.9〜2.5mm の一致を確認している。

> Liu C-F, et al. *Digital 3D Brain MRI Arterial Territories Atlas.*
> Scientific Data 10, 74 (2023). © 2021 The Johns Hopkins University

左右を neurological にしたのは 3D モデルに合わせるため。モデルは常に解剖学的な向きに
あるので、radiological（画像の左が患者の右）へ切り替えるとモデルと断面で左右が食い違う。

## できないこと

用途は参照実装。臨床で使うものではない。

- 被験者ごとの MRI には対応しない。同梱の標準脳 1 例に固定してある
- 領域数を数百規模に増やすと、色から領域を逆引きする作りが破綻する。現状でも左右は
  同じ色（95 領域に対して 53 色）で、world x の符号で左右を判別している
- 4096×4096 のテクスチャを使う。`gl.MAX_TEXTURE_SIZE` がそれ未満の環境は対象外で、
  そのとき何が見えるかは確認していない
- 【未確認】タッチ環境での操作は検証していない

## 用語

| | |
|---|---|
| world RAS | 実寸のミリ座標。+X が右、+Y が前、+Z が上。MNI 座標と同じ考え方 |
| DKT | 皮質の区分法（Desikan-Killiany-Tourville）。片半球 31 領域 |
| 血管支配 | どの動脈が詰まるとどこが傷むかの区分。ACA / MCA / PCA / VB |
| 断面板 | 切り口に置く矩形。ここに MRI と領域色を貼る |
| クリップ平面 | この面より手前は描かない、という 3D 表示の指定 |
| アトラス（テクスチャ） | 多数の画像を 1 枚に敷き詰めたもの。断面 256 枚が 1 ファイルに入る |

「アトラス」は脳の区分（DKT・血管支配）と、画像を敷き詰めたテクスチャの両方を指す。
文脈で読み分けてほしい。
